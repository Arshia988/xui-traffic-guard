# 🛡️ XUI Traffic Guard

پنل وب سبک برای **نمایش مصرف حجم سرور** همراه با پنل ثنایی (3x-ui) و **خاموش کردن خودکار سرور** وقتی مصرف به سقف تعیین‌شده (مثلاً ۱ ترابایت) برسد.

## ❓ چرا؟

پنل ثنایی حجم ارسال و دریافت سرور را از لحظهٔ روشن شدن سرور حساب می‌کند. برای همین **بعد از هر ری‌استارت این عدد صفر می‌شود**. ولی دیتاسنتر مصرف را برای کل ماه حساب می‌کند.

XUI Traffic Guard مصرف را خودش جمع می‌زند و روی دیسک نگه می‌دارد. وقتی سرور ری‌استارت شود، برنامه آن را تشخیص می‌دهد و شمارش از همان عدد قبلی ادامه پیدا می‌کند.

## ✨ امکانات

- 📊 نمایش آپلود، دانلود، مجموع، باقی‌مانده، درصد مصرف و سرعت لحظه‌ای
- 💾 ذخیرهٔ مجموع مصرف؛ با ری‌استارت پاک نمی‌شود
- ⛔ کار هنگام رسیدن به سقف: **خاموش کردن سرور**، **توقف x-ui** یا **فقط اطلاع‌رسانی**
- ⚠️ هشدار در درصد دلخواه (پیش‌فرض ۹۰٪)
- 📅 ریست خودکار ماهانه در روز دلخواه (مثلاً روز تمدید سرور)
- ⏳ مهلت بعد از بوت: اگر سرور به‌خاطر سقف خاموش شده باشد و دوباره روشنش کنید، چند دقیقه وقت دارید سقف را بیشتر کنید یا مصرف را صفر کنید
- 🤖 اعلان تلگرام (اختیاری)
- 🔐 ورود با رمز عبور
- 🔌 دو منبع داده: مستقیم از سیستم (پیشنهادی) یا از API پنل ثنایی

## 🚀 نصب سریع

روی سرور با کاربر root این دستور را اجرا کنید:

</div>

```bash
bash <(curl -Ls https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/xui-traffic-guard/main/install.sh)
```

<div dir="rtl">

اسکریپت این کارها را خودکار انجام می‌دهد:

1. پیش‌نیازها (Python3 ،Flask ،Requests) را نصب می‌کند.
2. برنامه را در `/opt/xui-traffic-guard` قرار می‌دهد.
3. چند سؤال می‌پرسد: پورت، رمز، سقف حجم، نوع اقدام و تلگرام.
4. سرویس systemd می‌سازد تا برنامه با هر بار روشن شدن سرور خودش اجرا شود.
5. اگر ufw فعال باشد، پورت را باز می‌کند.
6. آدرس پنل و رمز ورود را نمایش می‌دهد.

بعد از نصب، آدرس `http://IP-سرور:8088` را در مرورگر باز کنید.

## 🔄 به‌روزرسانی و حذف

اگر همان دستور نصب را دوباره اجرا کنید، منوی زیر نمایش داده می‌شود:

- به‌روزرسانی (تنظیمات و آمار مصرف حفظ می‌شود)
- نصب مجدد و تغییر تنظیمات
- حذف کامل
- نمایش اطلاعات

همین کارها را بدون منو هم می‌شود انجام داد:

</div>

## ⚙️ تنظیمات

همهٔ تنظیمات از داخل پنل وب قابل تغییر است. اگر بخواهید دستی ویرایش کنید، فایل `config.json` را باز کنید و بعد سرویس را ری‌استارت کنید.

| کلید | توضیح |
|---|---|
| `port` | پورت پنل (پیش‌فرض 8088) |
| `panel_password` | رمز ورود پنل |
| `limit_gb` | سقف حجم به گیگابایت (1024 = 1TB) |
| `warn_percent` | درصد هشدار |
| `action` | `shutdown` یا `stop_xui` یا `notify` |
| `reset_day` | روز ریست ماهانه (0 = غیرفعال) |
| `boot_grace_min` | مهلت بعد از بوت به دقیقه |
| `source` | `local` (مستقیم از سیستم) یا `xui` (API پنل ثنایی) |
| `xui_url` | آدرس پنل ثنایی همراه webBasePath، مثلاً `http://127.0.0.1:2053/abc` |
| `tg_token` / `tg_chat_id` | اعلان تلگرام |

## 💡 نکات مهم

- **منبع داده:** حالت `local` همان آماری را می‌خواند که پنل ثنایی نمایش می‌دهد (ترافیک کارت شبکه)، ولی به پنل و یوزر و پسورد آن نیاز ندارد. برای همین پیشنهاد می‌شود.
- **محاسبهٔ دیتاسنتر:** این برنامه ۱ ترابایت را ۱۰۲۴ گیگابایت حساب می‌کند. بعضی دیتاسنترها ۱۰۰۰ گیگابایت حساب می‌کنند. برای اطمینان، سقف را کمی پایین‌تر بگذارید (مثلاً ۹۵۰ گیگ).
- **ترافیکی که ثبت نمی‌شود:** ترافیک بین آخرین بار خواندن آمار (هر ۱۵ ثانیه) و لحظهٔ خاموش شدن ثبت نمی‌شود. این مقدار ناچیز است.
- **امنیت:** رمز پنل را قوی انتخاب کنید و در صورت امکان پورت را فقط برای IP خودتان باز کنید.
